# Semi Senti — 기능 데모 나레이션 & 자막

각 기능을 소개하는 **데모 영상 제작용 대본**입니다. (영상 파일 자체는 포함하지 않습니다 — 아래 자료로 직접 녹화하세요.)

## 구성

| 파일 | 내용 |
|------|------|
| `narration.md` | 기능별 나레이션(말할 내용) 프로즈 대본 + 녹화 팁 |
| `srt/01-screener.srt` | 스크리너 자막 |
| `srt/02-home.srt` | 종목 대시보드(홈) 자막 |
| `srt/03-chart.srt` | 캔들차트 자막 |
| `srt/04-news.srt` | 뉴스 자막 |
| `srt/05-finance.srt` | 재무 자막 |
| `srt/06-admin.srt` | 관리자 자막 |

## 녹화 방법 (권장 흐름)

1. **앱 기동**
   - 백엔드: `python -m semi_senti.api` (→ http://localhost:8001)
   - 프론트: `cd web && npm run dev` (→ http://localhost:3000)
   - 데이터가 비어 있으면 먼저 `collect_all_data.bat` 로 수집.
2. **화면 녹화** — OBS Studio / Windows 게임바(`Win+G`) / macOS `Cmd+Shift+5` 등으로 화면 캡처.
3. **나레이션** — `narration.md` 를 읽으며 녹음(직접 음성 또는 TTS).
4. **자막 입히기** — 편집기(예: DaVinci Resolve, CapCut, 클로바노트)에서 해당 `.srt` 를 불러오면 타임코드에 맞춰 자막이 얹힙니다.
   - 유튜브 업로드 시엔 `.srt` 를 자막 파일로 그대로 첨부 가능.

## 자막(SRT) 타이밍 안내

- 각 SRT 는 **0초부터 시작**하는 독립 타임라인입니다(기능별로 클립을 나눠 녹화한다고 가정).
- 타임코드는 표준 낭독 속도 기준의 **예상치**입니다. 실제 녹음 길이에 맞춰 편집기에서 미세 조정하세요.
- 한 클립을 이어붙일 경우, 뒤 클립 타임코드에 앞 클립 총길이를 더하면 됩니다.

## 다루는 기능 (6종)

1. **스크리너** — 반도체 종목을 지표별로 한눈에·정렬
2. **홈(신호등 대시보드)** — 매수/관망/매도 신호와 그 근거
3. **차트** — 일·주·월봉 캔들차트
4. **뉴스** — 종목 뉴스 + 감성 분위기
5. **재무** — 매출·이익·PER/PBR/EPS 카드와 적정가 밴드
6. **관리자** — 종목 관리 + 시스템/데이터 신선도 모니터
